# 会话命名与开工提示词

计划已确认并持续执行，当前分工见[看板](../board.md)。**沿用tim为各会话配置的模型和推理设置，PM派发时不覆盖。** 以下角色名保持；历史建议不再决定当前模型。

| 名称 | 职责与启用条件 | 提示词 |
| --- | --- | --- |
| PM | 当前任务统筹、具体卡片、验收与连续派发 | [PM](PM.md)（迁移PM时使用） |
| ARCH | 只在有具体架构问题时只读工作 | [ARCH](ARCH.md) |
| DEV | 一次一张READY卡，独占产品实现 | [DEV](DEV.md) |
| QA | 对明确冻结候选独立验证 | [QA](QA.md) |
| ART | 等tim明确授权视觉精修后启用 | [ART](ART.md) |

沿用现有任务，不同时启动空闲角色。初始化只适用于首次尚未获得READY任务卡的会话；额度中断或上下文压缩后，继续最近已派发卡，复用代码/证据，不重复初始化。完成卡片后交结构化报告并停止，由PM验收后派下一张；PM已获持续推进至全站推广的授权。
