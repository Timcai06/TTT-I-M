## 原因与修改

Index 的正常投影盒按显示器 1.8731 的比例排版；没有
`data-archive-sample-owner` 时，CSS 回退规则却覆盖为整屏宽高、取消比例和居中外边距。
`ArchiveStage` 在首帧获得所有权之前测量并保存页面尺寸；首帧设置所有权后，
CSS 改变盒子尺寸。下一帧的尺寸一致性校验失败，清除所有权并隐藏房间，
页面再次变为回退尺寸。滚动重试会重复这一循环。

修复保留投影与回退状态下相同的盒子尺寸、比例和外边距；回退仍允许显示文字、
清除投影变换并恢复交互。没有删除布局一致性检查或无模型时的可读回退。

新增构建回归检查禁止所有权相关的 Index CSS 规则更改被测量的布局属性。
该检查在原代码上失败，修复后通过。此次检查补上了之前数值投影测试未覆盖的
CSS 状态尺寸变化；没有进行浏览器、截图或前端效果验收。

正式发布包含此前的印刷品阴影修复、三轮模型优化及本次 Index 修复。
