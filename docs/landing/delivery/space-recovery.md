# 空间初始化与转场叠层修复

> 本页前一轮的叠层修复未覆盖用户随后提供的六张截图。投射副本、波浪叠层与资产变换的处理已由 [黑块与错误投影修复](spatial-artifacts.md) 替代；此前测试通过不代表这些现象已经消失。

2026-09-08，桌面 Landing。接续[温暖档案室](warm-archive.md)，处理「空间不可用」与视角切换黑色叠影反馈。视觉验收由 tim 完成；本轮只做资源、状态、DOM 和几何检查，没有截图或美术评价。

## 原因与处理

- 窄预览窗口完成开屏后再展开，空间没有参加初始准备。旧适配器把尚未准备直接判为失败；现在按共享资源生命周期补齐准备，取消一个适配器不会中断其他消费者。
- 空间运行时热更新会清空 GPU 实例，但开屏仍保持已完成。现在该模块更新后重新进入完整开屏准备流程，避免残留适配器引用旧实例。
- 共享 Canvas 切换持有者及离开空间时，旧章节投射 DOM 没有显式隐藏。现在切换、解绑和销毁都会隐藏旧页。
- 投射副本继承了章节黑底，Stack / Work 的全宽黑色伪元素也被克隆到物件上。现在限定在投射层内清除这些背景，保留纸张到正文的颜色过渡，原章节背景保持原样；Life 投射副本的照片墙底色同样透明。
- 四角投射拒绝近裁切面之前的坐标，避免无效透视继续形成覆盖层。
- About → Life 靠近书架时，旧轨迹部分位置距家具约 7 cm。进照片之前增加朝房间一侧的弧线，保持目标定位点及最终阅读机位。
- 投射矩阵同时拒绝非有限坐标、翻折和退化四边形，避免错误矩阵把整页反向展开到视口。
- GPU 上下文中断不再直接锁死为永久失败：立即隐藏 Canvas 和纸页，暂停绘制，恢复事件到达后重新上传贴图、生成环境反射、编译材质并绘制当前滚动位置。恢复中跳章会跟随新章节；离屏恢复不会抢占页面。15 秒未恢复或绘制出错时显示重试入口，重新经过完整开屏准备，也可直接阅读。
