# 书本、明信片和照片光照交付 · 2026-09-12

## 行为

保留已获 tim 认可的书本光照修复。Three.js r182 显式使用 PCF 阴影过滤；动态书页、明信片、照片与纸质背板不再携带静止姿态烘焙出的 AO/间接光。

明信片使用哑光响应，足球照片使用轻微清漆与柔和反射，纸边降低法线强度。印刷层接收光影，实体纸背板负责投影，避免两层重复投射黑边。Life → Frame 搬运代理继承源照片及背板的投影/受影设置，重建后仍保持一致。原始图片与共享材质纹理不改写，材质副本在释放时恢复并清理。

木质表面、墙面和静态纸面的 AO/间接光以 256 samples 重烘焙，排除会移动的四组墙上印刷品、Life 照片及信封盖。使用原 UV2，只替换六张接收面贴图，保留原房间的其他烘焙。重建流程及导出说明已同步更新。

当前方案继续使用 Three.js / WebGL，不增加渲染后端。太阳过滤半径为 3 texel，不把固定宽度过滤称作距离自适应半影或动态全局光照。
