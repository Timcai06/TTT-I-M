## 已发送给 DEV 的具体审查意见

1. renderer antialias 不代表 composer 中间目标有抗锯齿；选择内格式实际支持的采样，不能只看 MAX_SAMPLES。
2. 原 alpha===0 检测不能证明 alpha:false 输出没有不透明黑块。保留源 HDR 非有限值检测，补最终房间异常覆盖证据。
3. 核心影片不能与可选声音一起取消加载门禁；素材必须在开屏阶段准备好，不能进入章节才回退原 URL 补载。
4. Hero 的窗口 scrollY/事件/尺寸假设须转换为屏幕语义，不能只加 matrix3d。
5. 持续 canvas 与透明边框只是基础；需完整内容收回、物件记忆、真实相机连续与全章行为。
6. 不可用“待 tim 视觉验收”替代尚未开发的返回、导航、缓存等功能。
