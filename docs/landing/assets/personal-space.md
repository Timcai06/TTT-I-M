# 个人空间资产制作

状态：材质与物件细化迭代，最终美术质量待 tim 验收。

## 资产层次

- 建筑：窗洞、墙面、地板、踢脚线；建立空间关系。
- 家具：桌板、金属支架、档案柜、书架、椅子；轮廓和接触关系清楚。
- 近景交互：笔记本封面/书脊/纸页、抽屉/档案夹、照片/夹具、显示器；保留独立节点与枢轴。
- 生活细节：陶瓷杯、钢笔、绿植、书脊、纸张、五金；优先细化会进入近景的对象。

## 材质与光照

木材使用有方向的纹理，墙面使用低对比颗粒，纸张和布面具有细微表面变化，金属通过粗糙度与边缘形状表达。当前材质图由确定性的数学过程生成，非实拍扫描，不使用用户参考图直接贴整面家具。

颜色、粗糙度和切线空间法线采用可嵌入 glTF 的纹理节点。Blender 程序节点不能自动完整带入网页，因此不交付仅在 Blender 中有效的复杂节点材质。贴图打包进工程与 GLB。

主光为窗侧冷色柔光，台灯为局部暖光，低强度补光保留暗部层次。Blender 离线光照与网页实时光照分别配置；当前不承诺像素一致。网页使用有限阴影预算；最终灯光烘焙与真实设备性能仍需后续专项处理。

## 导出约束

Blender 工程保留可编辑对象；网页导出可按材质合并非交互静态网格。笔记本与档案夹等交互节点不合并。`NotebookHinge` → `NotebookCover` 和 `NotebookOpen` 动画契约保留。几何、GLB 字节、纹理数量与材质契约由脚本记录，预算属于技术上限，不代表视觉合格。
