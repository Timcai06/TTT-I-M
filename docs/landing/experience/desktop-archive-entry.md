# 桌面书页叙事

状态：本地开发完成，视觉效果由 tim 验收；未部署。

## 体验路径

原 Hero → 房间显现 → 封面展开 → 真实 About 档案出现在纸面 → 镜头对正并靠近 → 页面占满屏幕 → 原 About 正文 → 结尾页 → 退回书本 → 镜头移向书架 → 信封打开、真实照片抽出并靠近 → 原 Life。

不以空间淡出代替进入书页。页面是一份与正文共用的 `AboutDossier`，利用相机投影计算四角透视，最后归正至视口矩形；纸色同时衔接原站配色。接近时是不可交互且从无障碍树排除的展示副本，交接后由原语义正文与解密效果接管。

Life 使用模型内已打包的第一张真实照片作为抽出物。照片近景之后以正常滚动进入既有 Life，尚未把 Life 全章变成照片内部的连续表面。Frame、Stack、Work 保留现有实现。

## 时间编排

入口容器 340svh，实际滚动 240svh；末尾与 About 首屏重叠 100svh，避免两个相同首屏先后出现。

| 入口进度 | 动作 |
| --- | --- |
| 0–12% | 房间显现 |
| 8–42% | 从入口靠近桌面 |
| 22–48% | 笔记本封面打开 |
| 42–54% | 纸面内容显现 |
| 48–94% | 镜头继续接近、对正纸页 |
| 80–100% | 投影四角归正到视口边缘，纸色接续原站 |
| 100% | 展示副本隐藏，原正文接管，房间释放 |

About 后的退出段长 300svh，实际滚动 200svh。0–24% 结尾页从全屏恢复纸面透视，8–48% 镜头退至书桌，50–90% 转向书架，72–98% 打开信封并抽出照片，86–100% 镜头靠近照片。全部由滚动位置采样，可倒滚；无强制点击或新建 Lenis。

## 实现职责

- `chapters/about/index.ts`：保持纵向章节入口契约，导出 `ArchiveAbout`。
- `ArchiveAbout`：只在桌面普通动态模式组合入口、原 About、退出；保持真实 `#about` 导航锚点。
- `PersonalArchiveBridge`：sticky 几何、共享滚动刷新、正文可见性交接与失败退路。
- `pageProjection.ts`：CSS 矩形到纸面四边形的单应投影。
- `ArchiveRoom`：相机、纸面投影、三条模型动画和环境反射。
- `PersonalArchiveSurface`：近场加载、共享 context 配额、中止与 GPU 资源清理。
- `AboutDossier`：书页与 About 共同使用的真实开头排版。

用户的手机端及 Studio 范围保持暂缓。减少动态效果仍走原始章节。

## 画质与资源

空间高档位 DPR 上限从 1.5 调为 2，其他档位沿用已有质量配置；阴影从 1024² 调为 2048²；各向异性采样最高 8，受设备能力限制；添加预过滤环境反射以支持木材和金属的粗糙度表现。按需渲染和离场资源清理保留。

木材颜色/法线/粗糙度贴图升至 1024²，其余五类主材质升至 512²。GLB 当前 12.68 MiB、125 个网格，模型预算单独设为 14 MiB。纹理依然是程序生成，不代表实拍扫描或已经完成视觉验收。

现有 `art/personal-archive/source/tim-cai-personal-archive.blend` 原位更新。`upgrade_reading_surface.py` 加载该文件并升级，`reading_details.py` 维护可重建的书页、信封和照片动画；不生成新的 blend 文件，不渲染。
