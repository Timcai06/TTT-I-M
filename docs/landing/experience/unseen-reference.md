# 重点参考：Unseen Studio · 实站设计研究

状态：2026-09-05 完成首轮桌面浏览器操作研究。用户指定的首要参考，本文更新此前仅基于公开文本的初步记录。

## 研究范围与证据边界

直接访问并操作 [首页](https://unseen.co/)、[Projects](https://unseen.co/projects/)、[World](https://unseen.co/world/)、[Contact](https://unseen.co/contact/)。观察截图及页面可访问结构；实际完成无声入场、首页滚动、菜单开关、作品滚动、Experiment 分类、项目卡片点击、World 拖动、联系意图切换。

桌面实际视口为 1496 × 812。请求窄屏覆盖后页面仍报告原尺寸，因此不将其当作手机研究结果。未听声音，未完成 Click & Hold、减少动态效果或性能测试。未审查站点实现源码，本文不推断具体框架、着色器或灯光烘焙技术。

这次研究的是参考站。没有查看或验收我们的 portfolio 或 Blender 模型。

## 01 · 入场：先交代品牌，再释放空间

**观察**：浅粉米色满屏背景，中央小幅卡通眼睛、工作室名称、紧凑的三行介绍，下方白色胶囊 Enter 按钮；无声入口位于页面底部中央，是细小带下划线文字。大量留白使注意力集中。点击无声入口后，入场层消失，露出空间首页。刷新 World 也再次遇到入场层。

**设计作用**：入口只承担身份介绍和进入动作；声音选择在体验开始之前出现。眼睛图形让等待画面具有品牌性。

**我们的转化**：保留已有姓名排版与加载节奏，可以用纸张边缘、档案印记或局部窗光建立身份。不要照搬卡通眼睛或新增每次访问都必须点击的门槛。音乐仍为可选项。

## 02 · 首页：空间构图为标题服务

**观察**：拱门、台阶、狭长窗洞、浅色墙体、水面、石块和带珠光色泽的球体构成场景。台阶靠近中央，球体位于标题右后方，画面两侧的拱门和窗洞形成远近层次。水面倒影、颗粒、画面边缘的彩色分离和细小亮点让画面有摄影滤镜般的质感；这些是可见效果描述，不是对实现手段的判断。

标题居中，上方为很小的业务说明，中间第一行是高对比斜体衬线，第二行是大号无衬线，下面保留清楚的白色作品按钮。柔和低对比建筑背景与黑色文字形成主次。模型细节密度并不高，辨识度主要来自轮廓、构图、材质差异和光照关系。

**我们的转化**：先为现有 Hero 字体与行宽留出可读区域，再定窗框、台灯、书架的位置。桌面近景可以细致，但开场不必把整间房的所有物件都展出。木材/金属/纸张各自承担不同高光与表面变化，减少平均分配的装饰。

## 03 · 固定界面：稳定的导航包围变化的环境

**观察**：品牌位于左上；Index、Projects、Contact 和圆形菜单按钮位于右上。声音入口位于左下，World 球形入口位于底部中央。首页另外保留年度回顾入口和版权信息。顶部和底部控制位于画面边缘，中央留给标题和场景。

一次首页向下滚动没有出现新的长页章节，仍停留在空间首页。不能把它描述为已验证的长篇滚动叙事范例。

**我们的转化**：保留已有章节导航，让空间相机变化时用户仍知道当前位置和去向。首页的空间语气值得学，但主线继续采用我们已确认的滚动叙事。

## 04 · 菜单：保留环境的侧向阅读面

**观察**：点击右上按钮后，右侧约四成宽度出现浅色菜单，左侧空间保持可见。菜单采用大号文字和较小的 01–04 序号，包含 Index、Projects、Contact、World。当前 Index 呈灰色、带下划线；其他主要条目为醒目的衬线字形。关闭按钮变为黑底白叉；联系方式和社交链接被放到下部小字区。

**我们的转化**：未来需要展开章节目录时，保留一部分房间作为方位参照；以章节名字和序号形成索引。长篇内容仍进入正常网页阅读，不把此菜单模式直接当作正文容器。

## 05 · Projects：场景持续存在，作品获得清楚的网格

**观察**：页面背景换成更明亮的拱门空间；上方居中标题和紧凑胶囊筛选，下方为双列大幅作品。卡片有图片、项目名、简短类型说明、细分隔线和斜向箭头。此次 All 显示 20、Experiment 显示 6；数字仅代表此次访问。

向下滚动时，作品卡片向上推进，抓到卡片明显弯曲、翘起的过渡画面；顶部标题、筛选和全局导航继续可见。停稳后的卡片接近规则矩形。点击 Experiment 后，选中项变为黑底白字，作品集合替换，并显示该分类靠前的项目。

点击 Blossom 图片后，当前列表仍保留，新标签打开 `https://unseen.co/labs/blossom/`。这证明该实验卡片采用外开体验；不能推断所有项目都采用相同方式，也没有把它当作内嵌项目详情。

**我们的转化**：这是最值得借鉴的连接方式。我们的 Frame 和 Work 继续保留现有布局与阅读节奏，房间可以退到背景。已有 Frame 弯曲效果优先沿用和统一，不叠加另一套运动。速度相关的弯曲应只影响过渡中的视觉面，文字阅读时归于稳定。

## 06 · World：探索单独成为一种模式

**观察**：独立 World 入口切换为黑色背景、线框球体、带彩色分离/横向扰动的标志，以及拖动提示。第一次拖动后提示退场，球体周围展开生活照片与视觉实验图像。水平拖动改变图像位置，运动过程中出现连续重影拖尾；指针呈明显的像素手形。图像有透视角度和大小变化，形成球面排列的感觉。

从已筛选的 Projects 跳转 World 时，一次观察到旧标题和筛选栏残留；刷新并重新进入后消失。因此残留不列为设计手法，记录为此次跨页状态异常。具体原因未调查。

**我们的转化**：可将照片背面、生活片段和未展开的草稿作为额外探索，主线不依赖拖动。借鉴显式操作提示与模式区分，不复制球体布局或重影风格。跨章节状态应独立清理，导航跳转也应直接恢复正确场景。

## 07 · Contact：改变空间用途，延续视觉语言

**观察**：背景是带帘幕、抬高的平台、椅子、边几和拱门的浅粉空间；家具集中在下半部，信息位于上半部。大幅斜体衬线标题与小号说明并置。New Business / General 两个胶囊控制在描边与白底之间切换。

默认商业入口展示项目邮箱；点击 General 后切换到一般联系邮箱并增加两处地址。内容直接在当前构图中展开，没有跳出到表单，也没有要求先与家具交互。

**我们的转化**：结尾回到空间时，用打开的笔记本、稍微移位的照片表达来过的痕迹，联系方式仍是直接可用的文字入口。物件不承担所有功能。

## 08 · 转化为我们的下一轮设计工作

| 优先级 | 设计任务 | 落点 |
| --- | --- | --- |
| P0 | 先确定文字安全区，再安排开场镜头和家具轮廓 | 保留原站字体与留白，空间配合 Hero |
| P0 | 建立近景/阅读/交接三种镜头状态 | 移动用于章节交接，正文段落停稳 |
| P0 | 统一冷窗光、暖台灯和暗部层次 | 重点是光照关系与材质区别，不盲目增加纹理噪声 |
| P1 | 让照片或纸张与既有章节首屏形成视觉接续 | 原站 Frame / Work 展示方式继续承担内容 |
| P1 | 导航和关闭动作始终清晰 | 直接跳转与滚动都能恢复正确物件状态 |
| P2 | 照片背面、手稿与环境声音作为额外探索 | 主线无需点击、拖动或开声音 |

当前建模中已有木纹、纸纤维与细小五金，下一步应按文字构图和近景可见程度安排细化优先级。不能仅以网格数量、贴图分辨率判断设计成熟度。
