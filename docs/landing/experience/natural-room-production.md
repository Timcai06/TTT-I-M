# 自然光个人空间：制作与开发基准

2026-09-09 · 当前执行规范。优先于 spatial-experience-v2、spatial-art-direction-v2 中与本规范冲突的黑底和预算约束。历史交付保留原样，不当作当前验收结论。

## 目标与边界
进入网站即进入真实、温暖、有自然光的房间。Index 是电脑里可操作的真实首页；书、生活信件、照片墙、电脑、档案抽屉承载各章节。保留原站文案、字体、图片、排版关系与滚动节奏。空间贯穿阅读前后，黑色仅用于屏幕、金属、阴影和内容本身需要的视觉。禁止以灰色空档、黑色遮罩或无关标题卡掩盖交接。

由当前会话亲自完成建模及接入。仅桌面 Landing；不处理 Studio、手机端。唯一源工程 art/personal-archive/source/tim-cai-personal-archive.blend 原位保存，不新增 blend 或 blend1。用户本次已授权模型完成后接入网站。无自动提交、推送或部署。美术、样式验收由 tim 完成；工程检查只覆盖文件完整性、构建和核心运行行为。

## 参考图与空间
新母图决定背窗、森林湖面和远山的空间重心；新桌面近景决定胡桃木、纸张、玻璃、金属的细节；新结构图决定书架、书桌、照片墙和档案柜之间的关系。大窗是光源与空间延伸，不能被贴图中过曝的太阳或玻璃反射挡住。

远景采用高质量独立风景图，配合少量近景几何形成视差；保留旧几何景观在隐藏集合中。窗外图不包含房间、窗框、家具或文字。室内仍为真实几何。网页以轻微局部水面折射赋予景观生命，避免整张山景扭动。视频暂不作为必需依赖。

## 模型制作
1. 建立独立窗景与合理距离、完整覆盖所有室内镜头。保留玻璃菲涅耳反射，但保持通透。
2. 维持书页厚度、书脊、照片纸边、抽屉轨道、台灯和窗帘细节。调整窗光、室内反弹与台灯比例；木纹与纸张微凹凸不产生明显颗粒。
3. 保留书本、信件、抽屉动画枢轴及阅读定位面。入口、书本、屏幕、照片与档案的摄影机同步到网页契约。
4. 源模型保存与重开检查；网页导出仅修改内存，真实材质烘焙为可移植贴图；隐藏旧墙体、历史外景及体积盒不得重新进入导出。

## 网站呈现
| 章节 | 内容载体与交接 |
| --- | --- |
| Index | 自然光房间全景，真实首页投在显示器上，可点击、聚焦并返回 |
| About | 书翻开，完整头像、文案和档案排版投在纸上，逐步扩展为暖白纸面阅读；返回显示纸边书脊桌面 |

阅读页面与模型投影共用真实内容，不复制一套不同的标题或截图替代全文。源页面、投影页、目标页面的字体、边距、颜色与图像必须共享同一组样式。所有交接可逆、可中断，不强制播放等待，不因快速滚动遗留不可见点击层。

## 渲染与交互
Three.js/WebGL 负责空间、实时光照、反射和局部 shader 效果；HTML 负责真实排版、链接、键盘和可访问阅读；GSAP 负责既有滚动编排。Canvas 是承载绘制的画布，不是与 WebGL 互斥的技术。

房间观察时镜头轻微跟随鼠标，书页投影使用同一最终相机矩阵。进入阅读时跟随收敛为零，正文稳定。窗外水面仅局部微动，灯光无无理由的闪烁。不引入全屏流体扭曲、强颗粒或过度景深。

开屏退出以真实资源可用、纹理上传与场景预热完成为条件。常驻 canvas 不随章节卸载。保持现有 NaN 材质防护与后处理有限值隔离。资源大小记账，不以硬预算牺牲画面；隐藏标签停止持续绘制。保留失败恢复路径。
