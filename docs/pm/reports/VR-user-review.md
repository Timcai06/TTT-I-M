# 本轮前端验收顺序

供tim完成前端检验与效果测试。此表是检查路线，不是已通过记录；PM技术接受情况以最终验收报告为准。本轮已技术接受，局部增强与修复候选均已冻结；视觉接受等待tim。

## 本地主要反馈

1. 刷新进入：保留加载像素效果；结束后不再出现整层灰幕向上滑。电脑Index不再演示页面下滑，实际入口仍可点击。
2. 用相近幅度慢慢滚动每一段3D过渡，与2D阅读的推进感比较；中途停住、倒滚，观察镜头是否跟得上手势且不会突然飞过目标。
3. About进入与返回：留意书页到文字的接合；离开后倒滚，正文应先回到书页，再带走镜头。直接导航和从项目页面返回也检查一次。
4. About→Life：观察第三层明信片先移向柜外，镜头到达照片前方；往返检查柜板遮挡、穿模和照片突然变形。
5. Life→Frame：检查真实照片的连续移动与落位；不要把局部粒子标题误认为应恢复整张照片消散。
6. 六章配色：浅色阅读面检查正文、小字、链接和按钮；深色Stack检查浅色文字。重点看转场预览、真实正文、项目返回是否有瞬间错色。
7. 连续读到Contact再回较早章节：物件按故事位置复原，阅读书签保留。打开和关闭项目详情后，正文与点击应恢复。

## 局部效果

- About文字、现有Glass/Bend及本轮Work/Frame增强：优先判断正常内容始终可读，再看效果是否自然；快速离开再返回，不应残留遮挡或突然补播旧动画。
- Contact Liquid：仅Contact背景局部响应指针，文字和链接仍可使用；离开后不应覆盖其他章节。
- 窄屏或减少动态效果模式：正文、导航与链接可用，不要求全部增强效果出现。
