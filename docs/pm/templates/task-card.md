# 任务卡：PA-XXX · 标题

- 版本 / 状态：1 / DRAFT（只有 PM 派发的 READY 卡才能开始）
- 阶段 / 优先级：Sx / Px
- 负责会话：标题、thread ID
- 模型 / 思考强度：明确模型 ID 与强度
- 依赖：任务 ID 或无
- 目标：一句话写访客能感知或 PM 能核实的结果
- 问题证据：当前观察、复现步骤；未验证则注明
- 起始基线：由执行者记录 checkout、分支、HEAD、起始差异、范围文件哈希

## 输入与边界

- 必读：PM 入口、产品简报、具体代码/资料（仅相关部分）
- 可读范围：路径
- 独占写入范围：明确文件或模块；报告路径单列
- 不在范围：具体边界
- 同仓协作：你不是唯一执行者；保留他人改动，发现冲突立即报告
- 可挑战假设：尚未确认的实现选择及如何提交替代意见

## 交付与验收

1. AC-1：可观察的结果和验证方式。
2. AC-2：边界行为和验证方式。
3. AC-3：报告、证据路径、未完成项与回退说明。

- 必要检查：具体范围，不机械运行全套检查
- 视觉验收：需要 tim / 不涉及；开发须完成的功能检查另列
- 回退：仅本任务增量的恢复方式
- 停止条件：越界、写入冲突、证据失真、失败无法解释
- 回报：按 [报告模板](report.md)；建议主文控制在 60 行以内，长输出放证据文件
- 完成动作：回报后结束，不自行启动下一张卡
