# 会话命名与开工提示词

状态：计划待确认。以下名称与模型是建议配置；本轮没有创建、重命名或向新会话派发任务。

| 名称 | 模型 / 思考强度 | 何时启用 | 提示词 |
| --- | --- | --- | --- |
| PM | 当前 PM；建议 Astra high | 已有本会话 | [PM](PM.md)（仅迁移 PM 时使用） |
| ARCH | Astra high | 确认方向后的首张只读规划卡 | [ARCH](ARCH.md) |
| DEV | Sol high；局部明确任务 Terra medium | NR-00 通过后 | [DEV](DEV.md) |
| QA | Terra high；复杂渲染问题 Sol high | 第一份可验证交付出现时 | [QA](QA.md) |
| ART | Astra high | 样段稳定后按需 | [ART](ART.md) |

不是同时启动五个会话。先沿用 PM，确认后启用 ARCH；DEV 开发时 QA 可准备或复核独立证据，ARCH/ART 仅在必要时参与。模型需在会话设置或 PM 派发工具中选定；提示词中的模型文字不会自动切换模型。

每个文件“开工提示词”下方正文可完整复制。初始化只读三份短文档并返回简短理解，不触发完整仓库扫描、编码或测试。正式工作由 PM 单独发送 READY 任务卡，明确模型、文件所有权和验收项。
