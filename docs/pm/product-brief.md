# 产品简报

版本：1，2026-09-09。由 PM 维护。

## 当前意图

进入网站即进入 tim 的个人档案室。房间是持续存在的空间，电脑承载真实可操作的 Index，书、信件、照片、电脑与档案物件关联各章节。内容让访客理解 tim 的经历、作品与审美。

当前范围：桌面 Landing。Studio、手机端、Builder Graph OS 不自动纳入本阶段。用户于 2026-09-09 已授权本次 Git 基线提交和推送，保存到独立基线分支；这不构成后续每张任务的推送授权或生产发布验收。建模变更须进入专门的模型任务卡，本阶段启动盘点不修改 Blender。

## 当前连续执行授权

2026-09-09，tim 明确要求按既定协作方式持续推进，直到完成全站推广。PM 可在每卡验收后自主派发下一卡与必要定点修订，无需再次索要阶段开工确认；执行会话仍只执行自己被派发的任务卡，不越卡自行续接。

授权包括 NR-02 场景接管、NR-03 样段完整闭环、NR-04 全局协调、NR-05 各章推广及达到这些结果所必需的缺陷修复/技术回归。保持现有产品方向、真实内容与阅读书签；不自动扩大到 Studio、手机 3D 或新模型设计。

停止线：全站主要章节与入口已迁移，正反向、跳章、书签、布局/恢复和资源失败路径完成技术验收，并向 tim 汇报可体验版本与剩余问题。视觉精修、美术重设计、音效增强以及最终收尾/发布等待 tim 另行明确指示；不因原阶段编号靠后便提前执行。技术验证是本轮完成条件，不以此代替 tim 的最终视觉认可。新提交/推送继续按现有授权边界处理。

## 延续的用户决定

依据 2026-09-09 [当前执行修订](../landing/experience/natural-room-production.md) 顶部有效段落整理。用户后续意见可修订本简报。

- 保留个人空间、真实 Index 交互、完整内容和原图身份；About 全文与排版映射不可遗漏。
- 阅读颜色与实际受光房间纸面相联系，统一阅读体系；摄影、项目媒体保留自身色彩，Index 深色限于屏幕。
- 交接顺序表达为收回原物件、拉开、空间移动、对齐、靠近、展开阅读；正反向一致，导航可中断并能恢复阅读位置。
- 内容依附真实物件；去除游离于物件的跟镜头图片和掩盖问题的重暗幕。Frame 到 Stack 保持同图延续。
- 保留像素异常防护、加载可用性与 GPU 恢复。不可在内容不可用时用虚假的 100% 表示完成。
- tim 负责最终画面、节奏和体验接受；PM 与开发负责完成实现、可用性检查和提供可靠证据。

## 物件记忆的当前决定

2026-09-09，tim 已确认：物件按当前故事位置复原，保留阅读书签。回到较早章节时，后续章节物件按故事状态收回；再次进入正文可恢复阅读位置。访问历史、预热和恢复不能隐式提高物件开合下限。当前不引入“访问过就永久打开”的用户状态。

## 资源体积的当前决定

2026-09-09，tim 明确体积不是硬性要求。保留体积测量和变化提示，不以压缩体积牺牲画质或效果；大小本身不阻断本阶段交付。加载可用性、实际卡顿、资源缺失和生命周期问题仍按真实体验检查。

## 可以重新设计的部分

相机曲线和距离、停留构图、光影比例、材质参数、排版细节、阅读提示、反馈节奏、性能实现和模块边界均可提出改进。旧方案中的精确百分比、文件结构、实现技术和未经验证的资源阈值不自动成为新任务硬约束。

每项改进说明：当前观察 → 希望访客感知的变化 → 方案 → 影响范围 → 验证方式。数值应来自样段与测量；不先写一套庞大规范逼实现迎合。

## 质量维度

| 维度 | 要回答的问题 | 证据 |
| --- | --- | --- |
| 画面 | 当前主体、空间层次、材质差异和文字是否清楚？ | 指定视口的真实页面观察；最终判断由 tim 给出 |
| 运动 | 停住、倒滚、跳章时是否仍然连贯、可控？ | 可复现操作与实际行为记录 |
| 内容 | 访客能否记住 tim 和代表作品？ | 真实文案与作品内容核对；不编造成果 |
| 交互 | 入口、返回、链接和阅读恢复是否可靠？ | 鼠标、键盘、导航、中断操作 |
| 运行 | 何时可用、哪里卡顿、失败如何恢复？ | 设备/视口/版本与对应测量、错误记录 |

不在未浏览现版本时填写视觉分数，不把其他版本的测试当作当前通过。
