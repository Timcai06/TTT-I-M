# EduCanvas 项目片 v3 · 设计方案

「一张照片，是一张数字表格。」

- 用途：网站 Work 章节 EduCanvas 卡片下的项目片（替换 v2），24 秒，1920×1080，30 fps，90 BPM（一拍 20 帧）。
- 本轮只做设计。不接入网站，不核对数字，不换真实录屏。
- 制作分工：
  - Blender 三维底片交给 Codex，提示词见 `codex-educanvas-v3-blender.md`。
  - 字、界面平面、颗粒、子帧运动模糊由 Remotion 合成。
  - 声音由 `sound.py` 生成。

## 一、v2 的问题（逐秒拆帧所见）

1. **意思太多。** 24 秒塞了 7 个意思：问候、打字、Agent Loop 环、回答、像素化、人像、片名。平均 3.4 秒一个，一个都没站住。
2. **看不清。** 七成画面是深灰底上的小元素。界面截图只占画面一半，输入框里的字在网站播放器里约 10 px 高。
3. **明暗是平的。** 全片没有一个高光主体，每一帧的亮度都挤在 10–30% 之间。
4. **环是示意图语言。** 细线加小字标签，像演讲稿，不像影片。架构已经由赛题片讲清楚，项目片不必再讲。
5. **最好的想法放错了位置。** 全片最好的想法是「在计算机眼里，图片是一张数字表格」。这是 EduCanvas 真正会教的一课，也是全片唯一有材质、有纵深的镜头。但它只有约 3 秒，还放在第 16 秒。

## 二、核心想法

**整支片只讲这一课。** 24 秒里，观众像学生一样学会一件事：

> 机器看到的是数字 → 数字排出特征 → 特征得出判断。

最后才揭示：教会你这一课的，是 EduCanvas。

- 产品是老师，影片就是这一课。不罗列功能。
- 功能与架构交给赛题片；项目片只负责让人记住一个画面和一句话。

照片沿用 v2 的人像（`life/football-portrait.webp`）：

- 人脸从数字里浮现，比任何物体都更能让人立刻认出「这是一张照片」。
- 它也和开场暗房片的人像显影呼应。

## 三、结构（36 拍）

| 拍 | 时间 | 镜头 | 画面 | 字（一镜一行） |
|---|---|---|---|---|
| 1–4 | 0:00–0:03 | **P1 一个像素** | 真黑里一个光点随拍呼吸，这是网站加载器的那个点。镜头推近，光点原来是一根像素柱的顶面，上面刻着「212」 | — |
| 5–13 | 0:03–0:09 | **P2 数字原野** | 微距，贴着柱顶高度滑行。数字在景深里进出。镜头经过的地方，柱子一排排从平地升到各自的亮度高度，像被叫醒。暖色主光低角度扫过 | 第 9 拍：「在计算机眼里，」 |
| 14–19 | 0:09–0:13 | **P3 拉远显形** | 同一个镜头连续升起、后退，整片柱阵显出一张脸 | 「一张照片，是一张数字表格。」停 2 拍，保证读完 |
| 20–27 | 0:13–0:18 | **P4 特征** | 眼镜边、眼睛、发际线这些「特征」柱升高并发紫光，其余柱沉下变暗。特征之间连出细线，脸变成一张特征图 | 「AI 先找特征，再做判断。」 |
| 28–31 | 0:18–0:21 | **学会了**（Remotion） | 特征图退成背景虚焦。EduCanvas 界面平面从柱阵里升起，大比例裁切，字高不小于 48 px。「✓ 回答正确」落下，掌握度环填满 | 「学会了，系统也知道。」 |
| 32–36 | 0:21–0:24 | **P5 句点** | 全场熄灭，只剩一根柱升起发光。镜头俯下，柱顶成为一个方点，匹配剪辑成「EduCanvas.」的句点 | 片名 + 一句副标 |

**转场全部是形状匹配，没有硬切。** 顺序是：像素 → 柱顶 → 原野 → 脸 → 特征 → 界面 → 像素 → 句点。只在两个强拍上允许直切。

## 四、视觉规则

- **明暗**
  - 每个镜头只有一个最亮区域。
  - 背景是真黑（约 #070708），不是深灰。主体高光要到 90% 以上。
- **两色光**
  - 主光用暖色，取产品笔触橙 #d77b5f；轮廓光用冷紫，取产品主色 #8e70c4。
  - 除这两色和照片本身的颜色外，不再出现饱和色。
- **字**
  - 一个镜头只出一行中文，1080p 下不小于 72 px，用 Noto Serif SC。
  - 字落在拍点上，至少停 2 拍，再按每秒约 5 个字留出阅读时间。
  - 三维画面给字留好负空间，统一放在左下三分之一。
- **镜头**
  - 每个镜头都有有动机的连续运动：推、滑、升、俯。
  - 三维部分由 Blender 渲染真实运动模糊（快门 0.5），合成层用子帧运动模糊。
- **动势**
  - 入场用缓出。
  - 只有句点允许物理回弹，全片就这一处，留给结尾。
- **连续性**
  - 光点、颗粒、字体都与网站和赛题片一致。
  - 片尾的句点和网站加载器的点是同一个点。

## 五、声音

- 沿用 v2 的五音动机（C–D–F–G–A 五声），按新的拍点重排：
  - P2 里，柱子被叫醒时有细密的颗粒声。
  - P3 显形时铺底和声打开。
  - P4 特征升起时，每一组特征响一个玻璃音。
  - 句点落下前留半拍完全安静，然后落下。
- 我听不到声音，只能给响度与峰值的测量数，听感由 tim 判断。

## 六、制作流程

1. **Codex 用 Blender 出静帧。** P1–P5 每个镜头先出一张 50% 分辨率静帧，tim 看过定调。
2. **Codex 出全分辨率序列。** 静帧通过后渲染 16-bit PNG 序列到 `tools/project_films/out/blender/P1…P5/`。
3. **Remotion 合成。**
   - 新建 `src/educanvas/v3/`，底片用 `staticFile` 引入，叠字、界面平面、颗粒、句点。
   - 用 `render.sh` 走子帧运动模糊。
4. **`sound.py` 生成配乐**，交 tim 审片。

v2 保留，不删，直到 v3 被接受。
