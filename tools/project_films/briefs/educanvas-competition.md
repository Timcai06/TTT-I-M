# EduCanvas 赛题片 · 分镜与旁白稿

- 赛题：JBGS-2026-02 多模态 K12 人工智能通识课教学助手对话智能体
- 时长：约 3 分钟（赛事无硬性规定）；1920×1080，30 fps
- 主线一句话（出自 EduCanvas `docs/01-product/05-核心闭环冻结.md`）：
  **别的工具让你「得到答案」；EduCanvas 要让系统知道你学到哪了——而且这个判断不是模型说的。**
- 画面原则：**核心演示全部是真实产品、真实模型（DeepSeek）、真实搜索的录屏**，由脚本驱动录制；
  动态设计（贯穿全片的光点、Agent Loop 的环、三维界面平面）只负责把“为什么”讲清楚。
- 所有数字只用 EduCanvas 仓库里有出处的实测数据，出处写在每段后面。

## 制作（已实现）

- 合成：`src/pitch/Pitch.tsx`（`Pitch` / `Pitch-sub` / `Pitch-preview`），时间表 `src/pitch/cues.json`（旁白时间点，画面与配乐共用）。
- 录屏：`npm run capture:loop`（EduCanvas 需在 127.0.0.1:3000 运行，DPR 2，4K 60 fps）→ `npm run capture:cut` 按片段重定时，
  写出 `src/pitch/clips.json`（每段的倍速与标记）。只有真实模型生成回答那段是 ×8，画面上标明；其余 1.1–1.9×。
- 标注钉在录屏页面坐标上（1920×1080 页面像素），随镜头移动；镜头推近时被限制在页面范围内。
- 声音：`python3 sound.py pitch`，配乐 + 界面音效 + 旁白（占位），旁白出现时配乐再压低 8 dB。
- 成片：`npm run render:pitch`（4 倍子帧运动模糊）。
- 3e 多模态暂未放入：语音听写在本机没有返回转写；图片上传需要一张猫或狗的照片来录。
