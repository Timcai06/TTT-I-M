# 01 · 北极星

## 愿景

Builder Graph OS 是一个 GitHub-native 的成长叙事引擎。它帮助开发者把散落的仓库、提交、PR、文档和部署记录，转化为一张能被理解、能被展示、能被复盘的个人 Project Graph。

最终用户打开它时，不应该只看到数据，而应该产生一种感觉：

> 原来我真的做了这么多。原来我的能力是这样长出来的。

## 目标用户

### 学生开发者

他们有课程作业、实验项目、算法练习、比赛项目、半成品和第一次部署。GitHub 很乱，但成长非常真实。产品要帮他们从混乱里整理出能力线索。

### 独立 builder

他们有很多小工具、AI 实验、side project 和快速原型。产品要帮他们证明「我能持续 ship」，并把项目之间的主题连接起来。

### 求职 / 申请 / 转码用户

他们需要把 GitHub 转化为可讲述的经历。产品要帮他们从 commit 和项目里提炼故事，而不是只生成空泛简历。

### 开源贡献者

他们的价值分散在 PR、issue、review、fork 和讨论中。产品要把协作痕迹也纳入成长证据。

## 核心情绪

- 成就感：我不是没有作品，我只是还没把它们组织起来。
- 清晰感：我的能力不是一堆标签，而是一条路径。
- 掌控感：我可以决定哪些经历公开，哪些只用于复盘。
- 继续前进：系统能告诉我下一步最值得打磨什么。

## 产品承诺

1. 连接 GitHub 后，用户能得到一张自己的 Project Graph。
2. 每个图谱节点都能追溯到真实证据。
3. AI 生成的是可编辑的成长叙事，不是不可质疑的评价。
4. 用户可以发布一个漂亮、可信、有证据链的公开主页。
5. 用户也可以只把它当作私密复盘工具。

## 与普通工具的区别

| 工具类型 | 常见能力 | Builder Graph OS 的区别 |
|---|---|---|
| GitHub profile README | 手写展示 | 自动从真实活动生成结构，再由用户修订 |
| 简历生成器 | 包装项目经历 | 先建立证据图谱，再生成叙事 |
| GitHub analytics | 统计 commits/stars | 解释成长、能力、项目关系 |
| AI chat over repo | 问答单个仓库 | 跨仓库理解用户的长期成长 |
| Portfolio template | 展示最终成果 | 同时展示过程、迭代和能力形成 |
